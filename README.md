# esi-mvp-course-notes

> 《端侧智能推理系统 MVP》课程的学习记录 ｜ ESP32-S3-EYE ｜ ESP-IDF 5.4.x ｜ ESP-DL / ESP-PPQ

本仓库记录了课程中 4 个案例的实现过程与实测数据——从**训练、导出、量化**，到把模型塞进芯片前的每一步。
每个案例都包含课程脚本、实测产物，以及一份实现说明（做了什么、怎么实现、实测结果、踩过哪些坑）。
